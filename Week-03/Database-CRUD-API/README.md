# Database CRUD API

A REST API built using Python, FastAPI, and SQLite for managing tasks.

## Features

- Create tasks
- Get all tasks
- Get a task by ID
- Update tasks
- Delete tasks
- SQLite database persistence
- Input validation
- Error handling
- Swagger API documentation

## Technologies Used

- Python
- FastAPI
- Uvicorn
- SQLite
