# FlyRank Auth API

A secure authentication API built using FastAPI and Supabase Auth.

## Features

- User Sign Up
- User Log In
- User Log Out
- JWT access token authentication
- Protected profile route
- Protected dashboard route
- Public information route
- Swagger API documentation

## Tech Stack

- Python
- FastAPI
- Supabase Auth
- JWT
- Uvicorn
