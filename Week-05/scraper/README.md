# The Polite Scraper

A small Python scraping pipeline that collects book information from
Books to Scrape and converts messy HTML into clean, validated JSON.

## Target Classification

**Target:** Books to Scrape  
**Website:** https://books.toscrape.com/

Books to Scrape is a public sandbox created for practicing web scraping.

**Scope:** Only the first 3 catalogue pages will be collected.

**Data collected:** For each book, the scraper will collect the title,
product URL, price, availability, rating, description, source page, and
fetch time.

**Robots.txt result:** HTTP 404 Not Found — no robots file found.

This target is appropriate for this assignment because Books to Scrape
is specifically provided as a practice sandbox for scraping.

I will not reuse this code on another site without checking its rules
and terms first.
