# Task CRUD API

A simple REST API built using Python and FastAPI to manage tasks.

## Features

- Create a task
- Get all tasks
- Get a task by ID
- Update a task
- Delete a task
- Input validation
- Error handling
- Swagger API documentation

## Technologies Used

- Python
- FastAPI
- Uvicorn
